# I do not have Git installed. What should I do?
Git is the tool that records changes and lets teammates work on separate branches. GitHub is the online service where the team can share branches and pull requests.
## Setup
1. Download Git from [git-scm.com](https://git-scm.com/downloads).
2. Install Git using the default options unless your instructor gives different instructions.
3. Create a GitHub account at [github.com](https://github.com/) if you do not already have one.
4. Ask your instructor or teammate for access to the tutorial repository.
5. Clone the repository to your computer.
After setup, open a terminal in the repository folder and check that Git is available with:
```text
git --version
```
The instructor should make sure every student has Git installed, a GitHub account, and permission to work with the repository before starting the workbook.
